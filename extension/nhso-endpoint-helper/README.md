# NHSO Endpoint Helper (ส่วนเสริม Chrome)

ทำ Endpoint "ยืนยันตัวตนแทนผู้เข้ารับบริการ" อัตโนมัติบนคอมของเจ้าหน้าที่ โดยใช้เครื่องอ่านบัตร Smart Card รับรองแทน ThaiD รายชื่อมาจาก NHSO Tracker และผลบันทึกกลับเข้า NHSO Tracker

## เครื่องที่ใช้ต้องมี

- Google Chrome
- เครื่องอ่านบัตร Smart Card และโปรแกรม Agent ของ สปสช. ที่ทำงานอยู่ ในหน้า "ยืนยันตัวตนแทน" ต้องไม่ขึ้นข้อความ "ไม่สามารถเชื่อมต่อ Smart Card"
- บัญชี NHSO Tracker ที่ได้สิทธิ์ "ทำ Endpoint ได้"

## ติดตั้ง (ครั้งเดียว)

1. คัดลอกโฟลเดอร์ `extension/nhso-endpoint-helper` ไปไว้บนคอมเครื่องนั้น
2. เปิด Chrome ไปที่ `chrome://extensions` แล้วเปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `nhso-endpoint-helper`
4. กดไอคอนส่วนเสริม แล้วเข้าสู่ระบบด้วยบัญชี NHSO Tracker (login นี้มีอายุ 12 ชั่วโมง)

## ใช้งาน

1. เสียบบัตรประชาชนของคุณในเครื่องอ่านบัตร
2. เข้าเว็บ สปสช. → เมนูตรวจสอบและยืนยันการเข้ารับบริการปิดสิทธิ (NHSO ENDPOINT) → แท็บ **ยืนยันตัวตนแทนผู้เข้ารับบริการ…**
3. แผงที่มุมขวาบนแสดงรายการของวันนี้:
   - **ติ๊กรายที่จะทำ** (หรือใช้ "เลือกทั้งหมด") แผงจะแสดงจำนวนและยอดรวมของรายที่เลือก
   - **เลือกวิธีกดปุ่ม "ตรวจสอบข้อมูลจากบัตร Smart Card"**
     - **กดเองทุกราย** (ค่าเริ่มต้น): ส่วนเสริมกรอกฟอร์มให้ แล้วเลื่อนไปที่ปุ่มพร้อมกรอบสีส้ม กดปุ่มนั้นเพื่อรับรองรายนั้น แล้วส่วนเสริมทำต่อจนบันทึก (รอได้สูงสุด 3 นาทีต่อราย)
     - **ให้ระบบกดให้**: ส่วนเสริมกดอ่านบัตรเองทุกราย ทำต่อเนื่องจนจบ
4. กด **อนุมัติและเริ่ม** ส่วนเสริมทำทีละราย: ค้นหา → เหตุผล → ค่าบริการ → อ่านบัตรผู้รับรอง → ความสัมพันธ์ → บันทึก → ปิดหน้าพิมพ์

ส่วนเสริมจำวิธีกดปุ่มที่เลือกไว้บนเครื่องนี้

ถ้าติดปัญหา เช่น อ่านบัตรไม่ได้, มีรายการรับยาผิดปกติ หรือปุ่มบันทึกยังกดไม่ได้ ส่วนเสริมจะ**หยุดทั้งชุด**และบอกสาเหตุในแผง ตรวจแล้วกดเริ่มใหม่ รายที่บันทึกแล้วจะไม่ถูกทำซ้ำ

ถ้ากดบันทึกแล้วหน้าเว็บไม่ยืนยัน (ไม่เห็นหน้าพิมพ์) รายนั้นจะถูก**พักไว้**และไม่ทำซ้ำ ให้ตรวจในเมนู "ค้นหา/ลบรายการที่ยืนยันแล้ว" แล้วแจ้งผู้ดูแลระบบให้ปลดล็อกถ้ายังไม่ได้บันทึก

บัตรที่เสียบอยู่ใช้รับรองทุกรายที่เลือกไว้ ตรวจรายการก่อนกดทุกครั้ง
